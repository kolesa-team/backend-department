# Interns
Интерн - первый шаг на дорожной карте разработчика в Kolesa Group

### Hard Skills
- Знание основ любого языка программирования
- Знание, что такое PHP (Go, Python, Java и т.д. в зависимости от команды) и готовность его изучать
- Понимание, что такое backend, API, БД
- Знакомство с клиент-серверной архитектурой 
- Знакомство с Git (clone, commit, push, pull)
- Умение работать в IDE

### Soft skills
- Уметь гуглить
- Уметь формулировать вопросы
- Быть ответственным: доводить задачу до конца, сообщать о проблемах

- Умение работать в команде, следовать правилам коммуникации
  
### Обязанности
- Иметь большое желание стать Back-end разработчиком
- Следовать внутренним стандартам и правилам разработки

# Juniors

Junior - это следующий шаг на дорожной карте разработчика. Разработчик становится полноценным членом нашей команды, способным брать задачи в работу и доводить их до результата под минимальным контролем

## Junior 1

### Hard Skills
- Язык программирования PHP (Go, Python, Java и т.д. в зависимости от команды)
  - Базовый синтаксис, типы данных
  - Условные операторы, циклы, функции
  - ООП: классы, объекты, интерфейсы, наследование
- Backend
  - Понимание принципов MVC, MVVM
  - Работа с SQL (select, update, insert, delete)
  - Знание HTTP методов get, post, put, delete 
  - Умение писать простые API и обрабатывать запросы/ответы
- Frontend 
  - Базовые понимание вёрстки (CSS, HTML, JS)
- Linux
  - Базовое понимание работы ОС: директории, пользователи 
  - Команды cd, ls, cat, mv, cp, rm, ssh
  - Умение работать в окружении разработки по ssh
- Инструменты
  - IDE (PhpStorm, VSCode, GoLand, IDEA)
  - Клиенты MySQL (например: DataGrip, HeidiSQL, MySQL Workbench)

### Soft Skills
- Иметь желание делать лучший в мире продукт
- Умение уточнять требования, задавать правильные вопросы

### Обязанности
- Взаимодействовать с QA-инженерами
- Исправлять баги
- Участвовать в code review
- Писать unit-тесты
- Писать рекомендации к тестированию
- Соблюдать поставленные сроки

### Материалы
- Основы PHP https://ru.hexlet.io/programs/php-basics-free
- Курс по GO https://ru.hexlet.io/programs/go-basics
- Курс по HTML https://code-basics.com/ru/languages/html
- Курс по mysql https://youtube.com/playlist?list=PLWx5a9Tn2EvHIXXPPWnYxW7oB3tHQwMk_&si=HHZ34sOh3t6sN7H7

## Junior 2

### Hard Skills
- Фреймворки (PHP, Go, Python, Java и т.д. в зависимости от команды)
  - Формы
  - Валидаторы
  - Роутинг
  - Файлы конфигурации
- Отладка кода
  - echo, printf, var_dump (xdebug, clockwork для PHP)
  - curl, postman
  - Логирование
- Обработка ошибок
  - Исключения
  - Учитывает негативные сценарии (валидация входных данных, таймауты, пустые ответы, ошибки сети/БД)
- Базы данных: 
  - Понимает назначение индексов и когда они нужны
- Linux
  - Понимание работы ОС: процессы
  - ps/top, tail/less, nano/vim, grep, chmod/chown
  - консольный текстовый редактор (nano или vim)
- Docker:
  - Понимать, что такое docker и зачем он используется
  - Понимать разницу между образом и контейнером
- Надёжность системы: 
  - Помогает команде в аварийных ситуациях

### Soft Skills
  - Конструктивно аргументировать свою точку зрения
  - Перенимать лучшие практики от коллег

### Обязанности
  - Следовать установленным процессам и стандартам без постоянного контроля
  - Своевременно сообщать о возможных срывах сроков, их причинах и иных проблемах
  - Предлагать план реализации задачи, предварительно декомпозировать задачу и оценивать время на ее выполнение
  - Взаимодействовать с другими командами разработки
  - Проверять, что выполненная работа соответствует бизнес-требованиям перед передачей в тестирование и после релиза
  - Исправлять причины багов
  - Вносить правки в техническую документацию
  - Участвовать в обсуждении и внедрении улучшений в процесс разработки
  - Информировать тимлида о проблемах, решение которых вне своей компетенции

### Материалы

## Junior 3

### Hard Skills
- Понимание клиент-серверной архитектуры
	- HTTP запросы и ответы, жизненный цикл запроса
	- Роли клиента и сервера
    - Базовые знания работы прокси серверов: как создаются хосты, как прокси сервер перенаправляет запросы
- Linux
	- df, du, free, top, htop, chmod, chown, scp
    - Работа с процессами с помощью команд: ps, top, kill,  systemctl/journalctl
- ООП: абстракции, инкапсуляция, полиморфизм, композиция
- NoSql базы данных
    - Умение делать операции: insert, find, update, delete
- Elasticsearch
    - Уметь делать операцию поиска по нужным полям. Уметь сортировать и пагинировать ответ
    - Знать, где применять match, а где term.
    - Операции для агрегации (terms, avg, min/max)
- Docker
  - Работа с контейнерами: Запуск, остановка, вывод запущенных контейнеров (ps, ls, run, exec, stop)
  - Знание структуры Dockerfile
  - Умение работать с docker compose
  - Может собирать образы на основе Dockerfile, используя директивы Dockerfile
- Мониторинг и логирование
  - Умение читать и фильтровать логи (Graylog, Loki)
  - Понимание какие есть метрики и алерты (Graylog, Grafana, Zabbix)
  - Умение определить состояние системы (dashboards, логи, алерты)

## Soft Skills
- Понимать, как задача влияет на цели бизнеса
- Умение разбирать причины своих ошибок и предотвращать их повторение
- Определять приоритеты между задачами и внутри задач

### Обязанности
- Сопровождать релиз своей задачи
- Декомпозировать и планировать ход реализации задачи
- Улучшать кодовую базу проекта
- Доводить до рабочего состояния любой смежный функционал, если он сломался в процессе работы над задачей

### Материалы

- Документация по Elastic https://www.elastic.co/docs/get-started

# Middles
Middle это серьёзный промежуточный шаг на дорожной карте разработчика. Middle разработчик - самостоятельная единица команды с четкими зонами ответственности и полномочий. Обычно специалист уровня middle влияет своей экспертизой на весь продукт и приносит существенный вклад в свой отдел

## Middle 1

### Hard Skills
- Рефакторинг:
    - Навыки применения техник рефакторинга с учетом бизнес потребностей
- Язык программирования:
	- Опыт работы с популярными расширениями и библиотеками
    - Написание надежного, расширяемого и тестируемого кода
    - Применение основных компонентов в работе (DI, routing, ORM, validation, security, scheduler, messaging, observer, configuraton и т.д)
    - Опыт конфигурирования интерпретатора
    - Опыт работы на дополнительном языке программирования
- Архитектура:
    - Знания и навыки применения паттернов проектирования
    - Знания принципов межсервисных взаимодействий
- Базы данных:
    - Оптимизация запросов
    - Применение индексов
    - Навыки проектирования оптимальных структур таблиц (применение нормализации и денормализации)
- Kubernetes:
    - Понимание всех основных компонентов
    - Умение работать с yaml конфигами
- СI/СD
    - Умение работать с CI/CD pipelines, налаживать их процессы
- Очереди
    - Умение настаивать очереди (queue) и обработчики (consumers)
- Linux:
	- systemd service unit
	- полноценное знание bash

### Soft Skills
- Объяснять технические вещи и возникшие проблемы понятным языком
- Эффективно переключаться между задачами с учетом приоритетов
- Контролировать своё развитие

### Обязанности
- Участвовать в менторстве более младших по рангу разработчиков
- Проектировать крупные фичи учитывая цели продукта/бизнеса
- Устранять и предотвращать аварии
- Взаимодействовать с другими отделами и командами (админы, core-team, аналитика) для достижения поставленных задач
- Активно делиться знаниями внутри команды
- Писать техническую документацию
- Отслеживать свои релизы через технические метрики и закладывать их мониторинг

### Материалы
- От middle 1 и дальше нужно улучшать и глубже погружаться в уже полученных знаниях 
- Применять нестандартные подходы для решения задач
- Читать больше официальной документации от производителя продукта
- Смотреть опенсорс репозитории на https://github.com/ 

## Middle 2

### Hard Skills
- Активно выделяет новый функционал в отдельные переиспользуемые модули и библиотеки
- CI/CD 
    - Самостоятельно настраивает сборку и развёртывание для новых сервисов или фич
- Контейнеризация 
    - Создаёт и оптимизирует production-ready Docker-образы
- Kubernetes 
    - Не просто работает с готовыми yaml конфигами Kubernetes, а самостоятельно пишет и изменяет манифесты
- Базы данных
    - Оптимизация сложных запросов, работа с составными индексами (mySQL, MongoDB)  
- Надёжность системы
    - Уделяет время проактивному мониторингу, создает дэшборды по своему функционалу и по критическому функционалу, который не был покрыт ранее
- Очереди 
    - Продвинутое использование (Dead Letter Queue (DLQ), Retry-стратегии, Батчинг, роутинг, разница в push и pull подходах к работе с очередями) 

## Soft Skills
- Договаривается о взаимовыгодных решениях в спорных ситуациях, находит компромиссы.
- Активно делится новыми знаниями с командой и за ее пределами (митапы, конференции, статьи, демо дни и т.д.)
- Выступает в роли наставника и ментора (онбородинг, развернутые и содержательные комментарии на код-ревью и т.п.)

### Обязанности
- Не просто проектирует фичи, а полностью отвечает за техническую реализацию крупной задачи (эпика), включая декомпозицию, планирование и координацию с другими разработчиками
- Находит узкие места не только в коде, но и в процессах разработки. Предлагает и внедряет улучшения, которые помогают команде работать эффективнее
- При проектировании новых фич отслеживает технические метрики, следит за показателями после релиза. При возникновении проблем предлагает варианты их решения
- Эффективно взаимодействует со смежными командами (админы, аналитики, QA) без участия тимлида, самостоятельно решая возникающие вопросы

## Middle 3
Это последний рубеж на позиции Middle.
На этом шаге вы должны стать более требовательными к себе, начать думать как Senior и поступать как Senior.
От вас ожидается углубленное понимание технологий, описанных в предыдущих пунктах, а также больший уровень ответственности и инициативности

### Hard Skills
- Архитектурные паттерны проектирования (API Gateway, Circuit Breaker, Event-Driven, SAGA, CQRS и т.п.)
- Чтение и редактирование Ansible плейбуков и ролей
- Понимание механизма транзакций, репликации, шардинга
- Понимание инструментов балансировки запросов (nginx, haproxy, envoy, ingress) 

### Soft Skills
- Выстраивает результативные межкомандные коммуникации, когда того требует задача
- Распределяет задачи между членами команды, согласовав с тимлидом, чтобы ускорить достижение результата в рамках эпика

### Обязанности
- При проектировании новых фич учитывает отслеживание технических метрик, следит за показателями после релиза. При возникновении проблем предлагает варианты их решения
- Сокращает TTM с помощью приоритизации задач, упрощения тз и выбора оптимального пути решения
- Распределяет задачи между членами команды, чтобы ускорить достижение результата в рамках эпика
- Помогает бизнесу, отвечает на его вопросы, дает экспертизу в рамках эпика на этапе дискавери

# Seniors
Senior - это ступень, подразумевающая очень высокий уровень технической экспертизы, ответственности и погружения в процессы бизнеса. Человек на этом уровне оказывает влияние своей экспертизой на всю компанию и весь технический департамент

## Senior 1

### Hard Skills
- Понимание принципов взаимодействия компонентов Kubernetes кластера. Умение читать события и логи приложения внутри Kubernetes, правильно реагировать на них и обеспечивать высокую доступность задеплоенных сервисов
- Навыки оценивать долгосрочные технические риски своих решений и решений команды, предлагать способы их предотвращения. При проработке решений видеть большую картину в целом (бэк, фронт, мобильные приложения, базы данных)
- Глубокое понимание транзакций в различных системах: реляционные БД (ACID) и NoSQL
- Умение осознанно выбирать СУБД под конкретную задачу, чётко понимая фундаментальные различия (реляционные/документные/колоночные/граф/TS), их ограничения и компромиссы (ACID/BASE, OLTP/OLAP, CAP), с обоснованием выбора метриками, рисками и совокупной стоимостью владения
- Формирование технических метрик своей команды. Организация их мониторинга, и реагирование в случае непредвиденных колебаний. Организация дашбордов в Grafana

### Обязанности
- Искать неэффективные места в коде и архитектуре. Контролировать технический бэклог команды
- Предлагать альтернативные способы проверки гипотез и технических решений, которые позволят получить данные быстрее или с меньшими затратами
- Участвовать в создании обучающих материалов и курсов
- Следить за трендами и самостоятельно изучать новые технологии, которые будут полезны команде. Делится знаниями с командой
- В сложных ситуациях предлагать нестандартные решения, координировать команду и доводить до результата
- Помогать выстраивать коммуникации; вести результативные переговоры в кризис
- Принимать решения с учётом влияния на команду/компанию, рисков и долгосрочных последствий
- Понимать влияние тех. показателей на KPI продукта; взаимодействовать с лидами/менеджерами и предлагать тех. решения


## Senior 2

### Hard Skills
- Знание принципов и опыт построения распределенных систем
- Создание сервисов, используемых несколькими проектами сразу
- Внедрение актуальных AI инструментов и применение их в практике или участие в интеграции в продуктах
- Понимание внутреннего устройства систем хранения данных:
    - mysql (понимать разницу MyISAM, InnoDB, XtraDB)
    - mongodb (InMemory, WiredTiger)
    - ceph
    - elasticsearch

### Обязанности
- Соблюдать баланс между архитектурными новшествами и достижениями целей бизнеса
- Давать экспертную оценку сроков в команде
- Оптимизировать архитектуру кода, работу с данными и сетью
- Поддерживать open-source библиотеки без ущерба для других обязанностей
- Предлагать и реализовывать улучшения для инженерных процессов в команде

## Senior 3

### Hard Skills
- Осведомлённость о современных технологических трендах
- Внедрение инновационных подходов/технологий с учётом интересов бизнеса и технических рисков
- Опыт построения архитектуры нового проекта с нуля

### Обязанности
- Выявлять и решать глобальные технические проблемы в рамках продуктов всей компании, в том числе прибегая к написанию собственного уникального ПО
- Полная техническая ответственность и контроль за качеством, стабильностью и производительностью сервисов
- Организовывать и управлять рабочей группой для реализации нового проекта
- Нести ответственность за техническую реализацию проекта 
- Делать технические решения так, чтобы они могли стать самостоятельными продуктами
- Участвовать вместе с руководителем отдела в формировании технологической стратегии отдела и отвечать за её реализацию
- Оптимизирует затраты бизнеса с помощью технологических решений
- Принимать участие в развитии и улучшения бренда компании
- Помогать выявлять и решать проблемы, мешающие развитию команды
