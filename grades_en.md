# Interns
An Intern is the first step on the developer career path at Kolesa Group

### Hard Skills
- Knowledge of the basics of any programming language
- Understanding what PHP is (Go, Python, Java, etc. depending on the team) and willingness to learn it
- Understanding what backend, API and databases are
- Familiarity with client-server architecture
- Familiarity with Git (clone, commit, push, pull)
- Ability to work in an IDE

### Soft skills
- Ability to google effectively
- Ability to formulate questions clearly
- Being responsible: finishing tasks and reporting problems
- Willingness to learn and accept feedback
- Ability to work in a team and follow communication rules

### Responsibilities
- Strong desire to become a Back-end developer
- Follow internal development standards and rules

### Materials
- Official documentation for [git](https://git-scm.com/) and [interactive application](https://learngitbranching.js.org/)
- Free course on coursera or udemy on the topic "Introduction to backend development"
- Completion of the school computer science program
- PHP course https://code-basics.com/ru/languages/php


# Juniors

Junior is the next step on the developer career path. A developer becomes a full member of our team, capable of taking tasks and delivering results with minimal supervision

## Junior 1

### Hard Skills
- Programming language PHP (Go, Python, Java, etc. depending on the team)
  - Basic syntax, data types
  - Conditional statements, loops, functions
  - OOP: classes, objects, interfaces, inheritance
- Backend
  - Understanding of MVC, MVVM principles
  - Working with SQL (select, update, insert, delete)
  - Knowledge of HTTP methods get, post, put, delete
  - Ability to write simple APIs and process requests/responses
- Frontend
  - Basic understanding of layout (CSS, HTML, JS)
- Linux
  - Basic understanding of OS concepts: directories, users
  - Commands cd, ls, cat, mv, cp, rm, ssh
  - Ability to work in a development environment via ssh
- Tools
  - IDE (PhpStorm, VSCode, GoLand, IDEA)
  - MySQL clients (for example: DataGrip, HeidiSQL, MySQL Workbench)

### Soft Skills
- Desire to build the best product in the world
- Ability to clarify requirements and ask the right questions

### Responsibilities
- Interact with QA engineers
- Fix bugs
- Participate in code review
- Write unit tests
- Write testing recommendations
- Meet deadlines

### Materials
- PHP basics https://ru.hexlet.io/programs/php-basics-free
- GO course https://ru.hexlet.io/programs/go-basics
- HTML course https://code-basics.com/ru/languages/html

## Junior 3

### Hard Skills

# Middles
Middle is a significant intermediate step in the developer career path.  
A Middle developer is an independent unit within the team with clearly defined responsibilities and authority.  
Typically, a Middle-level specialist influences the entire product with their expertise and makes a substantial contribution to their department.

## Middle 1

### Hard Skills
- Refactoring:
  - Ability to apply refactoring techniques considering business needs
- Programming language:
  - Experience working with popular extensions and libraries
  - Writing reliable, extensible, and testable code
  - Using core components in daily work (DI, routing, ORM, validation, security, scheduler, messaging, observer, configuration, etc.)
  - Experience configuring the language interpreter
  - Experience working with an additional programming language
- Architecture:
  - Knowledge and practical application of design patterns
  - Understanding of inter-service communication principles
- Databases:
  - Query optimization
  - Using indexes
  - Designing optimal table structures (normalization and denormalization)
- Kubernetes:
  - Understanding all main components
  - Ability to work with YAML configurations
- CI/CD
  - Ability to work with CI/CD pipelines and set up their processes
- Queues
  - Ability to configure queues and consumers
- Linux:
  - systemd service units
  - Strong knowledge of bash

### Soft Skills
- Ability to explain technical topics and problems in simple language
- Ability to switch efficiently between tasks based on priorities
- Ability to manage personal professional growth

### Responsibilities
- Participate in mentoring junior developers
- Design large features considering product and business goals
- Prevent and resolve incidents
- Collaborate with other departments and teams (admins, core team, analytics) to achieve goals
- Actively share knowledge within the team
- Write technical documentation
- Monitor own releases through technical metrics and ensure proper monitoring

### Materials
- From Middle 1 onwards it is important to deepen and expand existing knowledge
- Apply non-standard approaches to solving problems
- Read more official documentation from product vendors
- Explore open-source repositories on https://github.com/


## Middle 2

### Hard Skills
- Actively extracts new functionality into reusable modules and libraries
- CI/CD
  - Independently configures build and deployment for new services or features
- Containerization
  - Creates and optimizes production-ready Docker images
- Kubernetes
  - Not only works with existing Kubernetes YAML configs but writes and modifies manifests independently
- Databases
  - Optimization of complex queries and work with composite indexes (MySQL, MongoDB)
- System reliability
  - Performs proactive monitoring and creates dashboards for owned functionality and previously uncovered critical functionality
- Queues
  - Advanced usage (Dead Letter Queue (DLQ), retry strategies, batching, routing, push vs pull queue approaches)

### Soft Skills
- Negotiates mutually beneficial solutions in conflict situations and finds compromises
- Actively shares knowledge inside and outside the team (meetups, conferences, articles, demo days, etc.)
- Acts as a mentor (onboarding, detailed code review comments, etc.)

### Responsibilities
- Not only designs features but fully owns the technical implementation of large tasks (epics), including decomposition, planning, and coordination with other developers
- Identifies bottlenecks not only in code but also in development processes and proposes improvements to increase team efficiency
- Tracks technical metrics when designing new features and monitors them after release, proposing solutions if problems arise
- Efficiently collaborates with related teams (admins, analysts, QA) without involving the team lead


## Middle 3
This is the final stage within the Middle position.  
At this stage you are expected to become more demanding of yourself, start thinking like a Senior and acting like a Senior.

You are expected to have a deeper understanding of the technologies described in the previous sections, as well as demonstrate a higher level of responsibility and initiative.

### Hard Skills
- Architectural design patterns (API Gateway, Circuit Breaker, Event-Driven, SAGA, CQRS, etc.)
- Reading and editing Ansible playbooks and roles
- Understanding transaction mechanisms, replication, and sharding
- Understanding request balancing tools (nginx, haproxy, envoy, ingress)

### Soft Skills
- Builds effective cross-team communication when required by the task
- Distributes tasks among team members in agreement with the team lead to accelerate epic delivery

### Responsibilities
- When designing new features, ensures technical metrics are tracked and monitors them after release, proposing solutions when issues arise
- Reduces TTM by prioritizing tasks, simplifying technical requirements, and choosing optimal solutions
- Distributes tasks among team members to accelerate epic completion
- Supports business teams, answers their questions, and provides technical expertise during the discovery phase


# Seniors
Senior is a level that подразумевает a very high level of technical expertise, responsibility, and deep involvement in business processes.  
A person at this level influences the entire company and the whole technical department with their expertise.

## Senior 1

### Hard Skills
- Understanding principles of interaction between Kubernetes cluster components. Ability to read events and application logs inside Kubernetes, respond appropriately, and ensure high availability of deployed services
- Ability to evaluate long-term technical risks of their own and team decisions and propose ways to mitigate them. Ability to see the big picture across backend, frontend, mobile apps, and databases
- Deep understanding of transactions in different systems: relational databases (ACID) and NoSQL
- Ability to consciously choose a DBMS for a specific task, clearly understanding fundamental differences (relational/document/column/graph/TS), their limitations and trade-offs (ACID/BASE, OLTP/OLAP, CAP), with justification based on metrics, risks, and total cost of ownership
- Formation of technical metrics for the team. Organizing their monitoring and responding to unexpected fluctuations. Creating dashboards in Grafana

### Responsibilities
- Identify inefficiencies in code and architecture and maintain the team’s technical backlog
- Propose alternative ways to test hypotheses and technical solutions that allow faster or cheaper data collection
- Participate in creating training materials and courses
- Follow technology trends and independently study new technologies useful for the team, sharing knowledge with the team
- In complex situations propose unconventional solutions, coordinate the team, and deliver results
- Help build communication and conduct effective negotiations in crisis situations
- Make decisions considering impact on the team and company, risks, and long-term consequences
- Understand how technical metrics affect product KPIs and collaborate with leads and managers to propose technical solutions


## Senior 2

### Hard Skills
- Knowledge and experience in building distributed systems
- Creating services used by multiple projects simultaneously
- Implementing modern AI tools in practice or participating in their integration into products
- Understanding an internal architecture of data storage systems:
  - mysql (understanding differences between MyISAM, InnoDB, XtraDB)
  - mongodb (InMemory, WiredTiger)
  - ceph
  - elasticsearch

### Responsibilities
- Maintain balance between architectural innovation and achieving business goals
- Provide expert timeline estimations within the team
- Optimize code architecture, data processing, and networking
- Maintain open-source libraries without harming other responsibilities
- Propose and implement improvements for engineering processes within the team


## Senior 3

### Hard Skills
- Awareness of modern technology trends
- Implementation of innovative technologies considering business interests and technical risks
- Experience building architecture for a new project from scratch

### Responsibilities
- Identify and solve global technical problems across company products, including writing unique custom software when necessary
- Full technical responsibility for quality, stability, and performance of services
- Organize and manage working groups to implement new projects
- Take responsibility for the technical implementation of projects
- Design technical solutions that can evolve into standalone products
- Participate with the department head in forming the department’s technology strategy and ensure its implementation
- Optimize business costs through technological solutions
- Participate in strengthening and developing the company’s brand
- Help identify and resolve problems that hinder team development
